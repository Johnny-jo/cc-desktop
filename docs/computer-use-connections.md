# 电脑与浏览器控制

在“设置 → 操控”中分别启用桌面应用、Chrome 或 Edge。浏览器与 Windows 桌面使用不同执行器。

## 浏览器连接方式

| 模式 | 用途 | 结束控制时 |
| --- | --- | --- |
| 日常浏览器（extension） | 通过扩展连接选定配置，复用登录状态，可查询该配置的历史和书签 | 断开当前控制连接 |
| 独立窗口（isolated） | 为会话创建独立上下文 | 关闭自己创建的上下文和浏览器 |
| 已有浏览器（CDP） | 连接已经开启远程调试的 Chromium 浏览器，复用其现有页面和登录状态 | 断开连接，保留原浏览器和页面 |

CDP 模式填写 HTTP(S) 调试地址或浏览器级 WS(S) 地址，例如 `http://127.0.0.1:9222`。地址不支持嵌入账号密码、查询参数或片段；此版本没有 CDP 认证头配置。CDP 不安装扩展、不读取本地浏览器配置的授权、历史和书签。

对应设置数据：

```json
{
  "browser": {
    "type": "playwright",
    "browser": "chrome",
    "connection": "cdp",
    "cdpEndpoint": "http://127.0.0.1:9222"
  }
}
```

附加到已有浏览器的连接按资源获取进程间租约，防止多个 AgentOS 控制进程同时操作同一配置。同一连接内的工具顺序执行。连接取消后，排队中的动作不再执行；进程退出会释放独占句柄。租约用于协调 AgentOS，自身不阻止人工操作或其他应用连接浏览器。

使用过日常/CDP 浏览器工具的轮次完成时，会关闭该轮 MCP 连接并释放租约；下一轮按原 SDK 会话继续。独立窗口保持原有空闲回收策略。

`browser_release_control` 主动停止当前连接，后续工具调用被拒绝。关闭连接的清理不会替用户关闭原有页面；模型显式调用导航、关页等工具仍是独立操作。

## 独立验证结果

`browser_verify` 只读取当前页面，支持：

```json
{ "url": "https://example.org/complete", "text": "保存成功", "timeoutMs": 2000 }
```

URL 与完整当前地址精确比较，包含路径、查询和片段；文本是归一化空白后的可见文本子串。多个条件必须同时满足。等待上限为 10 秒。

- `observed`：观察到所有给定条件。
- `not_observed`：在等待时间内未观察到条件。
- `unavailable`：页面关闭、连接中止或无法完成观察。

结果包含页面标识、URL 和观察时间。验证失败不会重复点击、提交或上传。它证明的是给定页面条件，不能单独证明服务器或本地文件已经完成持久化。

截图结果附页面、URL、viewport、像素尺寸、scale 与时间。元数据采集失败或期间发生页面变化时标为不可用，保留原截图；不会为添加元数据额外截图。现有 Playwright 点击、输入和导航仍使用上游的动作后快照。

## Windows 滚动与拖拽

先用 `inspect_window` 获取目标窗口的 `sceneId` 与物理屏幕坐标。`scroll` 和 `drag` 消费这次场景；下一次动作需要重新观察。

滚动示例：

```json
{
  "windowId": "目标窗口ID",
  "sceneId": "刚返回的场景ID",
  "x": 500,
  "y": 400,
  "deltaY": -2,
  "deltaX": 0
}
```

滚动量单位为滚轮格，每轴范围 `-20..20`。垂直正值向上、负值向下；水平正值向右、负值向左。至少一个方向非零。

拖拽使用 `startX/startY/endX/endY` 与可选 `durationMs`（默认 500，范围 1–2000）。起终点及路径必须位于当前窗口，执行时核对实际命中窗口、前台、观察和几何信息；窗口移动、遮挡、用户移动指针或取消会中止。

两类动作都可传 `verifyText`，沿现有 UIA/OCR 回读返回执行与验证结果。验证失败不自动重放动作。拖拽取消时先释放本 helper 持有的鼠标键，再结束控制；无法确认状态时返回中断错误，要求重新观察。

指定管理员窗口的提升连接尚不支持滚动和拖拽，会明确拒绝；这些动作不会自动扩大授权范围。桌面输入租约、Esc 和 Ctrl+Alt+F10 撤销继续生效。
