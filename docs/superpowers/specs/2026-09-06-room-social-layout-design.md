# 群聊社交布局修订

本轮依据：用户 2026-09-06 提供的五张截图与明确修改要求，是上一轮群聊 UI 的定向修订。

## 范围与布局

1. 系统消息直接在时间线居中，淡色、小于正文；没有头像、姓名头或聊天气泡。保留消息文字及可访问的时间信息。
2. 人类和 Agent 的消息头只显示一个发送者名与时间。人类按实际发送者、Agent 按 Agent 席位解析。不得改动 authorUserId、席位绑定、提及目标或任务权限。人类柔和气泡、本人右侧；Agent 没有外层气泡。
3. 群列表使用双行：左侧群头像；第一行群名及右侧最后消息时间；第二行“昵称：消息摘要”，单行省略。没有自定义群头像数据时使用群名字首的本地占位头像，不扩展上传功能。最后消息来自真实时间线，撤回显示撤回提示，图片 / 文件显示类型占位；不将工具日志当成员发言。不新增群排序行为。
4. 聊天顶部只显示群名，以及协作开关 / 群设置图标。在线人数、连接、加密、扩展和活动信息放入现有群设置；邀请入口移入群设置。断线重连与待加入审批等实际操作提示保留，不将错误藏起来。
5. 协作栏保持任务 / 成员 / 活动的功能与键盘导航。采用紧凑的分段页签、清晰分组与任务行；待我确认优先，进行中其次，历史默认折叠；个人转交策略放入默认折叠的设置项，摘要可见。移除无任务时的重复计数 / 空标题。以 rem 和继承字号替代固定 px 字号，确保成员、活动、操作控件一起受全局字体大小影响。

## 方案取舍

选择修订现有三栏布局：保留用户已经使用的协作入口。未采用默认全隐藏侧栏（降低任务可发现性），也不采用大型仪表盘卡片（挤占聊天空间）。字号沿用全局 `--ui-font-size` / rem 链路，不添加第二套设置。

外部参考仅用于信息层级：[WhatsApp Desktop 官方介绍](https://blog.whatsapp.com/faster-speeds-and-improved-calling-for-whatsapp-desktop?lang=en)；用户截图是尺寸和内容排布的直接依据。微信官网本次未能访问，不声称已验证其最新版界面。

## 验收

系统消息无头像且居中；同名和异名发送者头均只出现一个实际发送者；群列表跨未选中房间更新摘要、附件和撤回不会泄露旧文字；顶部无状态行、设置保留状态和邀请能力；侧栏无固定 px 字号，狭窄布局和大字号可换行；审批和中断权限、显式 @、附件功能不变。

不改全局样式、普通会话、协议版本、账号、中继架构。不提交、推送、部署。在当前 `group` 脏工作区继续；本轮开始时全局样式 SHA256 为 `DEA8B2B3CB5DA652A493F03D81822E06AEF14FDF0F7F495CE028F9EAF6FE1C0D`。
