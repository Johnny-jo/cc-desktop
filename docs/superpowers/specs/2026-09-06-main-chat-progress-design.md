# 主聊天任务进度与实时执行设计

日期：2026-09-06。状态：用户已确认「按钮＋上拉面板」方案，可实施。

## 范围

仅主界面 AI 聊天（含复用 ChatPanel 的独立会话窗口）。保留群聊、任务执行权限、模型设置、附件、文件变更、历史分页等既有功能，不部署服务器，不提交或推送工作区已有改动。

## 已确认交互

- 输入框上方按需出现 TaskList 和 SubAgent 两个轻量描边按钮，带线性图标及真实数量。没有对应数据不占空间；完成后仍可打开。
- 点击向上展开详情，一次打开一个面板；面板限制高度、内部滚动，不推高聊天内容。任务列表展示标题和状态；子 Agent 展示任务、状态、耗时、进展和结果。支持 Escape、点击外部关闭及焦点回到触发按钮。
- TaskCreate、TaskUpdate、TaskList、TodoWrite、Task / Agent 使用对应清单或分支图标。
- 正在执行的思考和工具步骤在本轮正文末尾展示；并行步骤均可见。结束后从实时区移除，收进本轮顶部的「执行过程」。每个事件只出现一次，原始记录不删除，历史顺序不重排；错误仍有显著文字提示。
- 已完成过程默认折叠；用户主动展开后不被后续事件强制关闭。失败条目归档后仍可由标题提示发现。
- 新回答起点约为扣除输入框后的可用聊天区域 55%，最小必要留白代替固定 80% 高度占位。输入框到真实内容的安全间距为 24px。文本增长消耗占位，结束清除占位；用户主动上翻时不自动拉回，点击到底部恢复跟随。

## 数据正确性

- 任务以真实 ID 关联 TaskCreate / TaskUpdate / TaskList，更新成功才改变清单，不把 TaskUpdate 调用结束当作任务全部完成。
- 保存子 Agent 的调用 ID、父调用 ID及实际生命周期；后台启动的工具返回不是完成信号。订阅 SDK task_started / task_progress / task_updated / task_notification，只将可确定为 Agent 的任务放入 SubAgent 列表。
- 会话摘要保存轻量进度快照，独立于 40 条历史分页窗口。重启恢复时未结束 Agent 标记状态未知，不虚构完成；回退消息时从保留的完整记录重建快照。
- 旧记录缺少结构信息时不从截断摘要猜测任务 ID或完成比例。沿用 TodoWrite 结构化列表作为兼容来源。
- 仅增加可选数据字段及展示相关事件，不改变任务执行、审批或网络协议。

## 验证

使用真实纯函数测试归一化、ID 合并、后台状态、失败及重放；组件测试覆盖按需显示、计数、面板开关、图标与单次呈现；滚动几何测试覆盖起点、动态占位、输入框高度变化和手动滚动。运行 desktop / shared 全量测试、类型检查、构建与差异检查。真实窗口验收若环境不可用，明确记录限制。
