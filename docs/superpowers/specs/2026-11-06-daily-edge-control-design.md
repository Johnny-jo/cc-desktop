# 日常 Edge 浏览器接入

用户已选择连接日常 Edge，并要求网页标记为 `AgentOS：<对话标题的 10 字内概括>`。同时保留前一轮确认的登录状态复用、历史/书签查询、接管后立即可见的虚拟鼠标和取消控制。

## 行为

- 内置浏览器提供“日常浏览器”和“独立窗口”两种模式，日常模式通过官方 Playwright 扩展连接 Edge/Chrome；旧的内置配置默认使用日常模式。
- 日常模式使用所选配置目录；未指定时读取浏览器 Local State 的最近使用目录。扩展与历史/书签查询必须对应同一目录。
- 浏览器连接名、受控页面的控制条和标签标题使用统一的 `AgentOS：<摘要>`；摘要去除请求套话，最多 10 个可见字符。页面取消控制后恢复网站标题。
- 虚拟指针在页面接入时立即显示；仅在 Agent 工具执行期间跟随输入事件，点击显示反馈；取消后隐藏。
- 历史和书签通过两个按需只读 MCP 查询工具提供，返回条数有上限；不会把完整数据库或凭据装入模型上下文。
- 取消控制中断等待中的调用，阻止后续调用，释放扩展连接，保留日常 Edge 和用户标签页。
- 缺少扩展时显示官方安装入口和可操作的错误信息。安装扩展和首次选择共享标签页沿用浏览器自己的交互。

## 结构与验证

配置序列化和设置表单保存连接模式/配置目录；会话管理器将当前对话标题传给 MCP。资源目录内分别负责连接生命周期、页面指示器、标题摘要和只读浏览器资料查询。

通过共享配置测试、MCP 解析测试、临时 SQLite/书签文件测试验证参数和数据边界；通过独立临时 Edge 的真实 MCP 测试验证初始指针、标题、跳转、点击和取消。完成类型检查、Electron/Vite 构建，并单独检查真实日常 Edge 的扩展就绪情况。
