# 恒星群与近景行星实现计划

用户已确认同时需要星体分布疏密和可见的近景行星，延续现有镜头与星云实现。

**设计：** 银河远景使用五类恒星及按类型分配的亮度、颜色、点大小和同色辉光。旋臂包含离散年轻星团与较稀疏的间隔，银心偏暖但混有白矮星。蓝色恒星中少量采用艺术化紫色辉光，不新增真实的紫色光谱类别。银河中心为超大质量黑洞所在位置，视界在此尺度下不可分辨，不绘制巨大的黑色圆盘。近景是独立距离层，镜头靠近后显现岩质、带环气态和冰质行星，具有球面光照、不同大小与视差；这不是等比例天体模拟。

**文件：** `galaxy-particles.ts` 负责星类、星团和轨迹；`galaxy-canvas.ts` 负责辉光缓存和合成；新增 `galaxy-planets.ts` 负责近景位置与缓存球面纹理。沿用既有暂停、主题、减少动态效果与销毁逻辑。
