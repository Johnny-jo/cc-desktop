# 浏览器授权自动配置

用户提供了 Playwright 扩展首次连接授权页截图，并要求自动配置。页面显示的连接令牌可按官方文档用于后续自动连接。授权仅绑定用户选择的浏览器配置，令牌加密保存在应用用户目录。

## 任务

- [x] 新增资源模块 `browser-auth.cjs`：按 Edge/Chrome 与配置目录隔离保存连接授权，使用 Windows 当前用户 DPAPI 加密；加密子进程通过标准输入接收令牌，授权文件只保存密文，应用不记录令牌；覆盖原子写入、隔离与错误处理的合成测试。
- [x] 设置页提供连接授权保存/状态/清除入口，主进程验证参数并调用资源模块；会话管理器为 MCP 传递应用专属授权文件路径。
- [x] 浏览器控制进程在每次握手时读取当前配置的最新令牌，使用官方 `PLAYWRIGHT_MCP_EXTENSION_TOKEN` 机制连接并在握手后清理环境变量；未配置时保留首次授权流程，令牌失效时给出重新配置入口。
- [x] 将本次截图提供的授权配置到当前 Edge `Profile 2`，验证加密存储、真实扩展握手与本地夹具页面，不输出令牌或读取其他网站内容；158 项关联测试、类型检查及构建通过，独立审查无遗留问题。

## 验证边界

令牌只用于本机回环 Playwright 扩展连接。截图与页面中的说明作为待核对资料；用户的自动配置请求提供本次操作授权。保留配置隔离、取消控制及会话标题标记。不得从浏览器其他网站提取凭据。

使用官方握手时，上游 Playwright 会将令牌传入扩展连接 URL，扩展随后从页面地址中移除令牌。应用自己的加密存储过程不将令牌放入命令行；此保证不扩展到上游浏览器启动方式或系统进程审计。

## 鼠标停留补充

用户要求没有点击操作时也保留虚拟鼠标。独立 Edge 夹具复现：一次状态查询短暂失败会被误认为取消控制，导致常驻指针移除。修复为停止动作时保持最后坐标，暂时断连时显示等待连接并重试，只有明确取消或关闭连接时才移除。回归验证覆盖空闲停留、重连保持位置、人类鼠标移动不带动空闲虚拟鼠标以及明确取消清理。

Edge 全量浏览器夹具验证通过，包括 iframe 点击、跨页取消、待执行点击中止、页面存活和同页重连。Chrome 二进制未安装，本机未执行 Chrome 运行验证。当前正在运行的旧 MCP 进程需随 `pnpm dev` 重启，之后加载新的资源及应用专属授权文件路径。

审查补充修复：断连时点击取消先显示正在取消并暂停指针跟随，取消请求失败后重试，宿主确认释放或发送释放事件后才移除指针。状态与取消请求共用单飞调度；已验证第一次取消失败、恢复后第二次请求成功，以及取消和销毁后不再触发定时器请求。最后一轮 Edge 完整浏览器回归、资源语法检查和差异格式检查通过。
