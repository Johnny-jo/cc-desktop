## 实现范围

- 群聊任务 / 成员 / 活动页签与可收起侧栏，任务审批和原有权限保持；截图粘贴与发送等待状态；跨群切换时旧请求不更改新草稿；ctx 压缩后显示等待新用量。
- 群聊专用附件缓存、实际字节分块传输、SHA-256 校验、按可见引用授权、远端任务输入、原生保存和安全图片预览。
- 应用协议 3，加密 / 握手封装仍为 1。所有成员须使用本开发版本；未实现自动兼容旧版本。
- 发送回执独立持久化：防止 ACK 丢失、历史裁剪或重启后重复派工。重试期限见设计文档。

## 重点证据

实际服务及 WebSocket 集成测试覆盖：加密跨节点字节一致、真实图片和 UTF-8 内容进入远端 prompt、源文件消失、未知二进制仅下载、未发布引用拒绝、撤回 metadata 无法重新发布、上传阻塞时普通聊天继续、断线与任务中断不启动 SDK、磁盘写入失败不广播或派工、缓存失败清理、确认丢失后复用副本、回执独立于历史及重启恢复、过期 / 清理后的 id 拒绝执行。

独立审查提出的三项 Important 问题（撤回引用复用、历史裁剪丢失去重、失败批次占用缓存）已对应增加回归测试并修复；缓存回收在锁内再次核对在用状态。所有缓存删除仅针对可确认未使用的派生副本，不删除用户选择的原文件。
