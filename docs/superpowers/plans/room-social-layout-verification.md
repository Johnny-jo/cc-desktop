## 用户五点反馈

- 系统通知：去掉头像与姓名头，使用时间线全宽居中淡色文字；时间保留为辅助信息。非法时间戳不会导致通知崩溃。
- 协作字号：任务面板原有固定 11px / 12px 改为 rem，面板宽度、操作控件、成员信息按全局字号缩放。主窗口与分窗已有的 `--ui-font-size` 链路不变。
- 群列表：本地群名字首头像；第一行群名与右对齐真实时间，第二行发送者与消息摘要，超宽省略。新共享 helper 对齐消息实际发送者；工具日志、思考内容不替代成员发言；图片 / 文件有类型提示；撤回不泄露原文。主进程列表与所有房间快照更新同一路径，不额外读取归档历史。
- 顶部和协作布局：顶部仅群名、群设置 / 协作开关；连接、加密、扩展、活动和邀请置于群设置。任务统计进入任务面板；分段页签、审批优先、历史与个人转交策略默认折叠，策略当前值仍可见。
- 消息头：只保留一个实际发送者名与时间；人类右侧 / 左侧柔和气泡及 Agent 无外层气泡保持。头像提及、引用、撤回、附件、任务权限保持。

## 回归与审查

本轮先观察新行为断言失败，再实现并复测。时间线、群列表及状态、头部、策略、字体、邀请错误与弹层生命周期均有对应测试。
