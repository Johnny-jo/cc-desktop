# 浏览器输入来源隔离与 AgentOS 标签

**目标：** 自动化操作期间，物理鼠标不得带动虚拟鼠标；所连接标签组使用 `AgentOS：<10 字摘要>`。

**方案：** 不再用页面 pointer 事件判断操作来源。当前固定版本 Playwright 的本机服务器 instrumentation 提供自动化动作的最终主视口坐标，按当前上下文及运行状态转发给常驻指针。日常浏览器连接后，仅在本连接的扩展连接页调用 `chrome.tabGroups.update` 重命名自己的标签组。原生调试提示的扩展名称取自已签名扩展清单，单独核对可行的发布边界。

- [x] 在独立 Edge 中复现：等待中的 Agent 点击期间，原始 CDP 模拟人工移动和 iframe 输入不改变虚拟指针位置。
- [x] 新建自动化坐标来源模块并覆盖范围隔离、生命周期清理，移除主页面及 iframe 的 DOM pointer 监听。每个后端捕获自己的清理函数，旧后端迟到清理不会关闭新后端监听。
- [x] 验证通过官方扩展当前连接页重命名本连接标签组，不影响其他分组；改名前再次确认当前标签和组 ID，组被移走时放弃改名。真实 Edge 本次连接组名验证通过。
- [x] 运行关联单测、Edge 真实浏览器回归、类型检查和构建；独立审查复现场景确认两项生命周期/归属竞态均已修复。

## 部署边界

顶部原生调试提示的名称由浏览器从签名扩展清单读取。用户确认暂无扩展发布账号，因此继续使用官方扩展；当前修改统一标签组、网页标题及页面内指示器的 AgentOS 名称，未修改已签名扩展文件或浏览器安全提示。完整替换原生提示名称需要自有扩展发布渠道及连接协议/授权身份迁移。
