# CC Desktop 项目描述（截至 2026-08）

> 本文基于最近若干次 git 提交与**当前工作区尚未提交的改动**整理，描述项目现状与进行中的工作。项目整体介绍见根目录 `README.md`。

CC Desktop 是一个非官方的 Electron 桌面客户端，把 Claude Code（`@anthropic-ai/claude-agent-sdk`）包装成图形界面：三栏 UI（会话 / 对话 / 变更栏）、内嵌多标签编辑器、权限弹窗、消息级 rewind，以及一键切换到真 `claude` TUI 的 CLI 模式。近期开发主线是**协作房间（room）**：多人通过邀请码加入房间、席位绑定 Agent、远程执行、QQ 式群聊布局与独立窗口。

## 未提交改动（working tree，约 +1891/-167 行）

当前未提交的一批改动围绕五个主题，属于一次较大的**性能治理 + 多窗口路由 + 房间体验增强**，尚未入库。

### 1. 会话持久化与内存治理

- `SessionArchive` 引入 **transcript 分块格式 v2**：每个会话一个 `<id>.transcript/` 目录，`manifest.json` 做索引，每块 64 条消息；保存时用引用快照定位首个脏块、只重写尾部块并原子落盘；旧单文件格式透明迁移。分页加载只读与请求页相交的 chunk，不再整文件加载。
- `SessionManager` 三层治理：
  - **延迟合并落盘**：transcript 750ms / changes 400ms 合并高频写，关停时统一 `flushPendingPersistence` / `disposeAll`；
  - **SDK query 驻留上限**：最多 2 个活跃 query，空闲 60s 的会话被 park（继续时 resume 重开），按 LRU 回收；
  - **transcript 水合上限**：内存中最多保留 4 个会话的完整 transcript，其余走 archive 分页直读；新增 `getMemoryStats` 诊断。
- 事件批处理：`text_delta` 40ms 合并、`tool_progress` 250ms 按 toolUseId 去重，降低渲染端压力。
- `DiffTracker`：git 仓库下用 `git rev-parse` 探测（带超时与缓存）替代全树 mtime 扫描。

### 2. 多渲染进程事件路由（新增 `renderer-routing.ts`）

为"独立房间窗口 / 会话 detach 窗口"引入 `RendererScope`（`main` / `session:{id}` / `room:{id}`）：主进程按 scope 过滤广播，session 事件只发主窗口和对应 detach 窗口（并能找到关联房间窗口），room 事件按 `roomId` 路由。终端 PTY 记录属主窗口，data/exit 只回发属主，窗口销毁时自动清理其 PTY 防泄漏。

### 3. 房间：上下文占用、自动压缩、/stop、流式思考

- 协议新增：`RoomSeat.contextUsage`（used/limit/ratio）、`exec.result` 带 `compacted`、快照 `liveExec.thinking`、新帧 `seat.stop`。
- 席位上下文超过 0.75 阈值时**就地自动压缩**（不自动续跑），并在时间线记系统消息；远程节点随 `exec.result` 回报占用。
- 房主本机席位的 text/thinking 增量直接写入 `liveExec` 快照（800ms 节流），房间成员可实时看到**流式回复与可折叠的思考过程**。
- `@agent /stop` 指令：客人发 `seat.stop` 帧，宿主幂等中止对应席位（本机 abort 会话 / 远程 abortRemoteTurnsForSeat）；目前任何成员均可喊停，协议层无权限校验，属有意放宽。
- 渲染端：席位卡新增 ctx 占用徽标（按 ok/warn/danger 变色）、引用回复自动补 `@作者`。

### 4. 编辑器视图缓存（新增 `editor-buffer-cache.ts`）

`App.tsx` 只挂载活动 tab + 两个 LRU 邻居的 CodeMirror 视图（上限 3），其余卸载。卸载时把未保存内容、编码、光标、滚动位置存入 buffer cache（上限 8，**脏快照永不淘汰**），切回时完整恢复；用户显式关 tab 才丢弃。隐藏 tab 同时跳过文件变更探测与 diff 装饰订阅。

### 5. 测试覆盖

- 新增 `renderer-routing.test.ts`（scope 匹配）、`editor-buffer-cache.test.ts`（LRU 上限 / 脏快照保护）。
- 扩充 `session-manager.test.ts`（事件合并、落盘合并、LRU 内存上限等）、`session-archive.test.ts`（legacy 迁移、分页、脏尾块重写）、`room-turn-ask.test.ts`（上下文占用与自动压缩、seat stop 与本机流式，共 7 个新用例）。
