## 借 AI：席位双轴绑定（aiUserId / workspaceUserId）

- **执行轴拆分**：原 `executorUserId` 一轴拆成 `aiUserId`（用谁的模型）+ `workspaceUserId`（在谁的项目里跑），实现"用 B 的模型改 C 电脑的文件"。设计文档 `docs/superpowers/specs/2026-08-28-room-borrow-ai-design.md`；纯函数解析在新模块 `packages/shared/src/room-seat-bind.ts`（`resolveWorkspaceUserId` / `canKickMember` / `effectiveFilePolicy` 等）。
- **协议**：新增 7 种帧 `seat.update` / `member.role` / `member.kick` / `ai.share` / `ai.ask` / `ai.models` / `ai.http`；IPC 新增 `room:set-member-role` / `room:set-file-policy` / `room:set-ai-share` / `room:ask-ai-share` 四通道。
- **AI 借用中继**：新模块 `room-ai-proxy.ts`——文件主人机器起 `127.0.0.1` 环回 HTTP 代理，CPA 应答以 48KB base64 分片经 `ai.http` 帧转给 AI 主人；SDK 侧用 `ANTHROPIC_BASE_URL` 指向代理 + `room-borrow:` 令牌；`CpaSupervisor.getProxyTarget()` 提供 CPA origin/token；`SessionRunOpts` 加 `permissionMode` / `extraEnv` / `skipCpa`。
- **管理员角色**：新增 `admin` 角色，房主可提权/取消；管理员可改席位、踢普通成员（不能踢房主/其他管理员，不能改名/解散/提权）。
- **房间设置**：新增文件策略 `filePolicy`（allow/ask/deny）单选和 AI 共享 `aiShare` 开关。
- **在线状态**：成员加 `online` 字段与 `onlineCount`，快照/列表/Stage 显示"N 人在线"；掉线标离线不删除，手动重连恢复。
- **UI**：`RoomAddSeatModal` 加 AI 来源/工作目录两个下拉（对方未共享时可点"请求借用"）；`RoomStage` 加借用请求横幅（同意/拒绝）。
- **测试**：`room-borrow-ai.test.ts`（提权踢人、filePolicy、skipCpa 代理环境、借用授权、撤销回退）、`room-presence.test.ts`（在线计数/掉线/重连/离房）、`room-ai-proxy.test.ts`（分片往返）、`room-seat-bind.test.ts`，约 20 个用例。

## 踢人清理 + 分窗事件推送 + 界面放大

- **踢出/退出后席位解绑干净**：`RoomService.unbindMemberFromSeats()` 在 `kick()` / `leave()` 删人席后调用——接管标记释放、Agent 席位三个绑定（workspace/ai/executor）置空，沿缺省链回落房主，席位本身保留。此前踢人只删 human 席位，会留悬空绑定。
- **分窗实时刷新**：`RoomService` 构造函数加可选 `sendToAllWindows`，`bootstrap()` 注入 `sendToRenderer` 向所有存活 renderer 广播 `room:event`；独立群聊/会话分窗此前收不到房间事件。
- **界面放大**：`titleBarOverlay` 36→40px，`.side-rail` 48→54px，按钮与图标同步放大。
- **测试**：`room-kick-cleanup.test.ts` 三用例（host 端无残留、其他客人视角同步、Agent 席位解绑回落房主）。

## filePolicy=ask 审批落地 + 路径围栏 pathJail

- **ask 策略真正生效**：成员在工作区主人机器上发起任务前（宿主本地 `runAgentSeat` 与执行节点 `exec.run` 两条链路都覆盖），主人机器弹 `RoomPermAskModal` 遮罩审批窗（请求人/席位/项目路径/任务预览截 300 字）；120 秒无人响应按拒绝；拒绝在时间线留审计（`refuseUnapprovedTurn`）；任一窗口作答后其他窗口弹窗自动关闭（`resolved` 广播）。borrow-AI 与 join-device 审批也一并从内联横幅改为模态。
- **IPC**：新增 `IPC.roomPermAsk`（事件）/ `IPC.roomPermRespond`（invoke）；preload 暴露 `respondRoomPermAsk`；`room-service.ts` 加 `turnAsks` Map（挂起 Promise + 120s 定时器）。
- **路径围栏**：`SessionRunOpts.pathJail`，`pathJailViolation()` 用 `path.relative` 判越界（`..` 逃逸、跨盘符绝对路径均拒）；群聊席位/远程执行会话一律带 `pathJail: cwd`，越界的文件类工具直接 deny 不进弹窗。
- **测试**：`room-turn-ask.test.ts` 端到端（弹审批→允许才执行、拒绝留审计、allow 直通、客人本机弹审批）+ `pathJailViolation` 单测 8 例。

## 围栏加固两连修（PreToolUse 下沉 + Bash 逃逸封堵）

- **下沉 PreToolUse**（9820e07）：围栏原挂 `canUseTool`，只读工具（Read/Glob/Grep）根本不进 `canUseTool`，围栏形同虚设；改在 SDK query 的 `hooks.PreToolUse` 注册，每次工具调用（含 bypass 权限模式）都校验。顺手修系统消息排版，群聊「引用」按钮临时下线。
- **Bash 逃逸封堵**（b369713）：新增 `extractBashPathCandidates()`——正则抽取 Windows/Unix 绝对路径、`>`/`>>`/`<` 重定向目标、`cd/chdir/Set-Location/Push-Location` 参数、`..` 上跳；`pathOutsideJail()` 另拦 `~`/`$HOME`/`$env:`/`%USERPROFILE%` home 引用；裸 `cd`（回家目录）直接拒；文件工具 PATH_KEYS 补 `path` 别名。
- **再加固**（35b668c）：中段逃逸正则（抓 `cat sub/../../x`）、`pushd` 纳入拦截。
- **内置路径守卫 skill**：`skill-store.ts` 新增 `BUILTIN_PATH_GUARD_SKILL`（room-workspace-guard），启动时覆盖写入 `~/.claude/skills`；群聊席位首条 prompt 点名该 skill，让 AI 事先知道规则而非被拒后学习。
- **测试**：session-extras 新增 PreToolUse describe 5 例；room-turn-ask 新增 Write `path` 别名、重定向越界、`cd ..`、`python -c` 绝对路径写、`sub/../../`、`pushd ..` 等用例。

## 会话内存治理 + 渲染窗口路由（1656559）

- **转录分块存储 v2**（`session-archive.ts`）：单文件改 `manifest.json` + `chunk-000000.json`（每块 64 条），`saveSnapshots` 引用快照定位首个脏 chunk 只重写脏尾，`writeJsonAtomic` 原子落盘；旧版读取后下次保存自动迁移；分页只读相交 chunk。
- **SessionManager 治理**：`MAX_LIVE_QUERIES=2`（LRU `parkSession` 回收闲置 SDK 查询，60s TTL）、`MAX_HYDRATED_TRANSCRIPTS=4`；持久化防抖（转录 750ms/变更 400ms）；流式事件批处理（文本 40ms、工具进度 250ms）。
- **渲染窗口作用域路由**：新模块 `renderer-routing.ts`——每窗口注册 `RendererScope`（main/session/room），广播改 `sendToMatchingRenderers` 按 `acceptsSession/acceptsRoom` 过滤；PTY 加 `ownerWebContentsId` 归属路由，关窗 `killOwnedBy` 防 shell 子进程泄漏。
- **席位上下文徽标 + 自动压缩**：`RoomSeat.contextUsage` 字段，`exec.result` 回传占用，超 0.75 自动压缩并清零徽标；`RoomStage` 席位旁显示 `ctx xx%`。
- **@agent /stop**：新帧 `seat.stop`、新 IPC `roomSeatStop`、preload `stopRoomSeat`；远程席位由房主转发节点 abort。
- **房间流式思考**：`exec.event`/liveExec 加 `thinking` 字段，前端折叠展示。
- **编辑器缓冲缓存**：新模块 `editor-buffer-cache.ts`——最多挂 3 个 CodeMirror 视图，卸载存快照、重挂载恢复未保存内容/选区/滚动；缓存上限 8 且绝不驱逐 dirty 缓冲。
- **测试**：renderer-routing、session-archive（legacy 迁移/分页/脏尾重写）、session-manager（热查询上限/防抖/LRU/idle 关闭/事件合并）、room-turn-ask（占用快照/自动压缩//stop/thinking）、editor-buffer-cache。
