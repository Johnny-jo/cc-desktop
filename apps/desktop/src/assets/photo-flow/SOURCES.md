# Photo flow sample images

Bundled landscape, portrait, architecture, still-life, and abstract samples from Unsplash, downloaded 2026-10-30.
These bundled files are served locally as an offline fallback.
When Daytime photo flow is enabled, the desktop main process also fetches up to
12 thumbnails daily from https://picsum.photos/v2/list and caches them locally.
The renderer displays cached data only. Turning the feature off stops downloads.
Cached entries retain the author and source URL returned by Picsum. The cache
holds at most 48 images / 20 MiB; failed refreshes retain existing images.
