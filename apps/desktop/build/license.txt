Claude Desktop
==============

By installing this software you acknowledge that:

1. This package may include the Claude Code CLI binary and a local CPA
   (CLIProxyAPI) gateway for model routing. They run on your machine only.

2. You are responsible for providing your own API credentials / upstream
   model accounts. No third-party account credentials are bundled.

3. The gateway binds to 127.0.0.1 by default. Do not expose it to the network
   without understanding the security implications.

4. Application settings and chat data are stored under your user profile
   (AppData). Uninstalling the application does not delete that data unless
   you remove it manually.

5. This software is provided as-is. Use at your own risk.

Click "I Agree" to continue, then choose the install location. Installation
starts only after you confirm the directory and proceed.
